## Corrections to proposed fixes

### Token revocation (#3)

For provider-driven JWT revocation checks, the relevant Quarkus setting is `quarkus.oidc.token.require-jwt-introspection-only=true`. If results are cached, explicitly enable introspection caching, configure a nonzero `quarkus.oidc.token-cache.max-size`, and bound `time-to-live`; that TTL becomes a revocation delay. This also requires compatible provider introspection/authentication configuration and a tested latency/capacity budget. Simply setting `allow-jwt-introspection` and a TTL does not establish this behavior. [Quarkus token introspection and cache configuration](https://quarkus.io/guides/security-oidc-expanded-configuration/).

Authentik's current upstream refresh-token model explicitly survives browser-session termination, supporting the concern about relying on logout to revoke refresh credentials. Its end-session implementation can delete access-token records, so “logout invalidates no tokens at the provider” would be inaccurate. Locally verified JWTs can still work until expiry despite deletion there. These are upstream-source observations; the deployed Authentik version/configuration was not inspected. [Authentik refresh-token model](https://github.com/goauthentik/authentik/blob/main/authentik/providers/oauth2/models.py), [end-session implementation](https://github.com/goauthentik/authentik/blob/main/authentik/providers/oauth2/views/end_session.py).

### Privacy, caches and revisions (#8–#14, #26)

Reduce generic resets and repeated reads, but preserve immediate removal of revoked private views and the existing exclusion of private data from durable caches and offline writes. Event family/resource metadata can itself reveal private activity; classify what may be broadcast to whom before replacing the privacy-preserving generic event. A session cache and a near-cache need permission/version keys and recovery after missed events. Do not remove polling or transactional source versions until those guarantees have a tested replacement. Event timestamps alone are not commit-order versions.
